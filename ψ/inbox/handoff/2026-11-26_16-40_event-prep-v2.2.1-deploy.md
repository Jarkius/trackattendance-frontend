## Event-day flow (for the user)
1. Upload `C:\TrackAttendance` (or `dist\TrackAttendance`, about 753 MB) to the share; on
   each laptop run `deploy.bat` from the share as the kiosk logon user; give each station a
   unique name at first launch. `deploy.bat` skips a used install's database, logs and
   exports, and copies itself, so the installed folder is a valid source.
2. If a laptop does not pick up the Poly, change the camera in Admin (`.env` says index 1,
   which assumes a built-in camera at 0).
3. Rehearse with the event team. Then Admin -> Clear ALL stations on one station. Within one
   health check (~2 min) every online station clears and returns to the hold screen (block).
   Check the dashboard shows 0 scans and all stations online first.
4. At opening, press Esc on each station.
